1. Доделать CRUD Employees на клиенте
Кнопки "Редактировать", "Заблокировать/Разблокировать", "Soft delete" для каждой карточки
Форма редактирования (переиспользовать EmployeeForm с пропсами начальных данных)
Подтверждение удаления (модалка "Вы уверены?")

2. Навигация и Layout
Боковое меню (Sidebar) с пунктами: Сотрудники, Бригады, Работы, Базы, Должности
Шапка с именем пользователя и кнопкой "Выйти"
Адаптация под роль (Worker видит только "Профиль" и "Мои работы")

3. Страница Teams (Бригады)
Список бригад с фильтром по статусу
Создание бригады (форма: выбор лидера, название не нужно)
Назначение бригады на работу (assign/unassign)
Добавление/удаление участников

4. Страница Works (Работы)
Список работ с фильтром по статусу и типу
Создание работы (выбор типа, скважины, супервайзера)
Изменение статуса работы (draft → in_progress → completed → ...)
Просмотр назначений (WorkAssignment) внутри работы

5. Профиль пользователя
Страница /profile — просмотр своих данных
Редактирование своих email/телефона (Worker)
Просмотр своих бригад и работ

6. Универсальные компоненты (опционально, ускорит разработку)
ConfirmModal — окно подтверждения действия
DataTable — переиспользуемая таблица с колонками и действиями
